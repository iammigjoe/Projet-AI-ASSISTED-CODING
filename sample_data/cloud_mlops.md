# Cloud & MLOps

## Chapter 1 — Cloud fundamentals
On-demand self-service, broad network access, resource pooling, rapid elasticity and measured service. Service models: IaaS, PaaS, SaaS, FaaS.

## Chapter 2 — Containers with Docker
A Dockerfile describes an image. Build, ship (registry), run (container). Containers share the host kernel and are lighter than virtual machines.

## Chapter 3 — CI/CD
Continuous integration builds and tests every commit. Continuous deployment ships validated code automatically. Good practice: automated tests, rollback strategy, monitoring, separate environments.
